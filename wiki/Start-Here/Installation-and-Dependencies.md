# Installation and Dependencies

Parent: [Start Here](/mod/alecs-animal-husbandry/start-here) | [Home](/mod/alecs-animal-husbandry/)

## Required Mods
- [Alec's Animal Husbandry!](https://www.curseforge.com/hytale/mods/alecs-animal-husbandry)
- [Alec's Tamework!](https://www.curseforge.com/hytale/mods/alecs-tamework) `>=4.1.0 <5.0`

Alec's Nametags and Alec's Coops are optional companion mods.

## Installation Steps
1. Put all required mods into your Hytale Server/mods folder.
2. Start the server and check logs for asset errors.
3. Join the world and test one tame + command flow.

## First Login Checklist
1. Tame one supported animal.
2. Craft the Animal Control Flute.
3. Open the companion panel and select that animal for the flute.
4. Test Follow, Hold, and Recall.
5. Confirm the companion panel opens and stats are visible.

## Existing World Support
- Existing worlds are supported.
- Older vanilla-tamed entities may require one successful interaction/link to fully migrate ownership metadata.
